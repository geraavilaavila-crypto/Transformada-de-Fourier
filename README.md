# Transformada de Fourier
## Simulacion y analisis de la transformada de Fourier -- Propósito: Este repositorio contiene la implementación en Python de la simulación y análisis de señales elementales (pulso rectangular, función escalón y senoidal) mediante la Transformada Rápida de Fourier (FFT). El objetivo es comparar cómo se comportan las señales en el dominio del tiempo y de la frecuencia, y verificar propiedades fundamentales de la Transformada de Fourier como la linealidad, el desplazamiento temporal y el escalamiento en frecuencia.
